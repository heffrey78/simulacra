## Evidence pulled afterwards

- **Nothing crosses between worlds.** Each world is its own database, and the
  prose cache is keyed by theme. Mirrors and altars came from vocabulary the
  engine sends to every theme: the room *role* words — `shrine`, `vault`,
  `lair`, `chamber` — go to the director and the narrator verbatim, and the
  director overwrote Hardpan's own room names with the same clichés it gave
  simulacra ("Chamber of Shadows", "Lair of the Forgotten", "Descent into the
  Unknown" appear in both themes' worlds).
- **Motifs are a checklist stamped on every room.** Every room's prompt carries
  all the floor's motifs, and the director writes them as objects in particular
  rooms. The current world's entrance prompt contains *"A hollow statue in the
  lair"*, so the entrance describes the lair's statue. Run 1's motifs evidently
  contained room ids, which the narrator copied.
- **Word counts across the transcript:** `mirror` 16, `altar` 22, `key` 30,
  `torch` 25 — beside Hardpan's own motif words `tallow` 24, `dust` 36,
  `rust` 32.
- **All three runs went into one transcript file.** `--new-world` restarts run
  numbers at 1, and transcripts were named by run number only.
