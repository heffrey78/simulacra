## Search re-describes instead of adding

The run did 54 bare searches: 29 finds, 23 "You find nothing more here.", and 2
caches.

| of 29 finds | count | example |
|---|---|---|
| use the word for the fixture found | 10 | "the drill steel", "the tag board" |
| name it something else | 19 | tag board → "an iron sheet"; ore car → "an iron cage"; assay scales → "brass weights" |
| re-describe what the room already said | 2 | harness → the room's rusted lever; tag board → the Threshold's door |
| put the fixture on the delver's body | 6 | scratch marks → "a jagged ridge running up your thigh"; scratched date → "the ink on your wrist" |

Every follow-up on what a find mentioned failed: `take paper`, `open vent`,
`search vent`, `look at ribcage`, `search ribcage`. Only the fixture's own words
lead back to a find. `take scraper` was the one that worked, because "scraper"
is the fixture's word, and it got M14.1's "That's part of the room".

**Why:**
1. `Narrator.discover` uses the room narrator's system prompt, so it writes a
   room description: "You stand before…", second person, atmosphere.
2. It's given the room's name and concept, never its description, so it can't
   add to what the player read. The description isn't in the repeat check
   either, so a re-description passes.
3. Nothing requires the fixture's name in the text, and `look` never shows
   finds.
